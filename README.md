## The line

> Rack 4 is haunted. Do not reboot it — the ghost fixed the outage and now charges by the scream.

One funny line for the door of a haunted server room: Rack 4 is haunted,
and nobody may reboot it — because the ghost is the one who fixed the
outage, and it now bills by the scream. The setup is a normal server-room
warning; the payoff turns the haunting into an on-call engineer with a
billing model.

## Run it

```sh
python3 main.py
```

This writes the line (95 characters, one line) to `/output/entry.txt` —
valid UTF-8, inside the 1–120 character gate — and prints it to stdout.
